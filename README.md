# ⚡ Zephyr — Media & Gaming Hub

**Zephyr** es una consola multimedia de escritorio rápida, nativa y ligera diseñada para centralizar tu biblioteca local de películas y series, tus plataformas de streaming y tus juegos en una sola interfaz fluida y personalizable.

🌐 **Sitio Web Oficial:** [Visitar Zephyr Media Hub](https://sites.google.com/view/zephyrmedia/)  
📥 **Descarga Directa (Windows 10/11):** [Descargar Zephyr v1.0 (`Zephyr_Setup_V1.0.exe`)](https://github.com/zephyrmediahub/zephyr/releases/download/v1.0/Zephyr_Setup_V1.0.exe)

---

### ✨ Características Principales

* **🎬 Biblioteca Media Local:** Organiza tus películas, series y videos locales con miniaturas automáticas, portadas personalizadas y reproducción fluida.
* **💬 OpenSubtitles Integrado:** Busca y descarga subtítulos en Español, Inglés y Portugués con detección automática por Hash exacto de video o búsqueda manual.
* **🎮 Control Remoto y Xbox:** Diseñado desde cero para controles Windows Media Center (RC6), mandos de Xbox, controles Bluetooth y teclado/ratón, con teclado virtual flotante integrado.
* **🌐 Portal Web y Streaming:** Acceso directo en un clic a YouTube, Netflix, Max, Disney+, Prime Video, Crunchyroll y navegación web en pantalla completa.
* **🎨 Temas & Modo Proyector:** Adapta colores, fondos y escala de la interfaz con un solo botón para disfrutar tanto en escritorio como en proyector.
* **⚡ Nativo, Rápido y Ligero:** Compilado a código nativo de alto rendimiento con telemetría local en tiempo real de CPU, GPU y RAM.
